Про Booksy

Booksy — це невеликий цифровий простір для тих, хто любить відкривати нові
історії, знаходити цікаві книги та проводити час із користю.

Ми створили односторінковий сайт книгарні, де знайомство з наступною улюбленою
книгою починається всього з кількох кліків. Тут можна переглянути книжкові
новинки, дослідити різні категорії, дізнатися більше про конкретне видання та
навіть обрати кількість книг для замовлення.

Але Booksy — це не лише про книги. Це також місце для зустрічей із читацькою
спільнотою, знайомства з майбутніми подіями та пошуку інформації про саму
книгарню.

Що можна знайти на сайті?

∙Hero — знайомство з Booksy та візуальна презентація книгарні зі слайдером.

∙Books— каталог популярних книг із категоріями, фільтрацією та поступовим
завантаженням нових позицій.

∙Book Modal — детальні відомості про вибрану книгу,її ціну, автора та можливість
оформити покупку.

∙Feedbacks — враження читачів,представлені у вигляді інтерактивного слайдера.

∙Events — анонси книжкових зустрічей та інших цікавих заходів із можливістю
реєстрації.

∙Article — розповідь про ідею та атмосферу Booksy.

∙Location — контакти книгарні та карта для тих, хто захоче завітати особисто.

∙Footer — швидка навігація та підписка на новини.

Трохи про технічну сторону

Для створення Booksy використані:

∙HTML5 — структура та семантика сторінки.

∙CSS3 — стилізація, адаптивність та інтерактивні стани елементів.

∙JavaScript (ES6+) — логіка інтерфейсу, обробка подій, модальні вікна та
взаємодія з API.

∙Vite — інструмент розробки та збирання проєкту.

∙Swiper.js — інтерактивні слайдери.

∙Modern Normalize — узгодження базових стилів браузерів.

∙REST API — отримання актуальної інформації про книги та категорії.

∙SVG та WebP — робота з графікою й оптимізованими зображеннями.

Звідки надходять дані?

Книжковий каталог не є статичним: інформація завантажується з Booksy Backend
API. Основні запити: Що отримуємо Endpoint Категорії книг /books/category-list
Популярні книги /books/top-books Книги за категорією /books/category Інформація
про книгу /books/:id

Повна документація: Booksy API Docs.

Адаптивність та оптимізація

Booksy розроблений за принципом Mobile First. Інтерфейс пристосовується до
різних розмірів екранів, зберігаючи зручність користування та цілісність
дизайну.

Використані контрольні точки:

320px — мінімальна ширина мобільної версії. 375px — перехід до адаптивної
мобільної верстки. 768px —планшетна версія. 1440px — десктопна версія.

Окрема увага приділена оптимізації графіки: використовуються сучасні формати
зображень, підтримка Retina-дисплеїв та оптимізація завантаження ресурсів.

Запуск проєкту

Щоб запустити Booksy на своєму комп’ютері:

1. Склонуйте репозиторій: git clone <repository-url>
2. Перейдіть до директорії проєкту: cd <project-folder>
3. Встановіть необхідні залежності: npm install
4. Запустіть локальний сервер: npm run dev
5. Для створення готової збірки: npm run build

Про розробку

Booksy — командний навчальний проєкт, створений у межах навчання GoIT. Робота
над ним охоплює не лише верстку, а й взаємодію з API,реалізацію
JavaScript-функціоналу, адаптивний дизайн та спільну роботу з Git і GitHub.
